# table

Data table, used for tables authored in rich text on the source site (e.g. the COPD GOLD stage tables).

## Authoring (Document Authoring)

Model: `standalone`

One block row per table row, one cell per column. The first row is rendered as the header row.

## Supported variations

- `no-header`: render every row as a body row.
