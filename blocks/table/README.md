# table

**table** block from the AEM Block Collection (https://www.aem.live/developer/block-collection/table).

## Authoring (Document Authoring)

Model: `standalone`

Block table where each row is a table row and each cell a table cell. The first row is the header row (rendered as `th`) unless the `no-header` option is set. Used for data tables inside long-form legal text (e.g. the "Category of Personal Information Disclosed | Category of Third-Party Recipient" table of the Privacy Statement).

## Supported variations

| Variation | Option class |
| --- | --- |
| No header | `no-header` |
| Striped | `striped` |
| Bordered | `bordered` |
